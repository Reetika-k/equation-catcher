# Live gameplay demonstration (about 4 minutes)

Open the public URL (or `npm start` → http://localhost:8080) before the demo. Add `?seed=7` to the URL if you want the same numbers every time.

| Minute | Show | Say |
|---|---|---|
| 0:00 | Start screen: title, instructions, best score, Start Game | "Objective, controls and scoring are all on the first screen, as the PDF asks." |
| 0:30 | Play Level 1 with the arrow keys; catch a correct number (particles, +10, sound); catch a wrong one (shake, lost life) | "Every number looks the same, so you must actually solve the equation. Scoring, lives and the timer are the challenge mechanisms." |
| 1:30 | Clear Level 1 → level-up screen with time bonus → Level 2 | "Three levels: one-step, two-step, variable on both sides. Speed, decoys and bombs increase." |
| 2:15 | Press P (pause), M (mute); drag the basket with the mouse; resize the window to phone width to show the touch buttons | "Keyboard, mouse, touch. Sounds are synthesised in the browser, nothing to download." |
| 2:45 | Let the timer run out or lose three lives → game-over screen with final and highest score → Play again | "Win and loss conditions, restart and a saved high score." |
| 3:15 | Show `docs/VIBE_CODING.md` and `docs/TESTING.md` | "Built step by step with an AI coding assistant; every prompt, bug and fix is logged, and the game is tested both by logic tests and by an automated browser play-through." |

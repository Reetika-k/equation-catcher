4. AI coach: how the model was trained

The AI coach is a logistic-regression model that predicts the chance a player solves an equation on the first try, from 10 features: the equation's form (x + a = b, x − a = b, ax = b, ax + b = c, ax − b = c, x on both sides), the size of the answer, the size of the coefficient, whether a decoy is only 1 away from the answer, and negative constants. In the game it does three things: it predicts the chance for every equation (shown in the HUD), it learns from each first attempt of the player (online gradient steps on a personal skill offset and the weights, saved in the browser), and it picks each next equation from 5 fresh candidates so the predicted chance stays near 70 %. It is trained offline first, so a new player starts from a sensible model (npm run train → src/coach-prior.js).

Training data. 12,000 first attempts from 300 simulated learners (40 equations each, all three levels). Each simulated learner has a hidden skill, and a hidden "true" difficulty per feature decides whether they solve an equation. Real players were not recorded; the simulation lets the dashboard check whether training recovers the true difficulties. The split is by learner: 9,600 rows to train, 2,400 rows from learners the model never saw to test. Batch gradient descent on the log loss with L2 regularisation, 400 epochs.

9. Limitations

  • The difficulty figures come from scripted players, not people; a human play-testing session (the brief's step 11) is still to be recorded.
  • The browser play test is quoted from its recorded run; sound is verified only by the mute toggle.
  • Decoy "closeness" is measured, not its effect on real players.
  • The AI coach is trained on simulated learners; its accuracy on real players is not measured yet. In the game it keeps learning from each player's own attempts.

Reproduce

npm run train (trains the AI coach, writes src/coach-prior.js) → npm test → npm run test:tap (records the logic run) → npm run dashboard (seeded audit and simulations run inside the build, about 5 s). This file embeds its figures and screenshots.
